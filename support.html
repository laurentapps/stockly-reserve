Questions frequentes

Comment ajouter un produit ?

Depuis Stock ou un emplacement, utilisez le bouton +, scannez le code-barres ou ajoutez le produit manuellement.

Pourquoi un produit n'a pas de photo ?

La photo depend des donnees trouvees au scan ou d'une photo ajoutee manuellement. En foyer partage, sauvegardez vers iCloud pour l'envoyer aux autres appareils.

Comment synchroniser deux iPhone ?

Activez le foyer partage, invitez l'autre membre, puis utilisez Synchroniser maintenant apres de grosses modifications. Au demarrage, l'app recupere les changements disponibles.

Un produit supprime revient apres synchro.

Mettez les deux appareils a jour avec la meme version de l'app, relancez Stockly Reserve puis lancez une synchro manuelle sur l'appareil qui a fait les changements.

Le scan ne trouve pas mon produit.

Stockly Reserve utilise d'abord la base locale puis Open Food Facts. Si le produit n'existe pas encore, vous pouvez completer la fiche manuellement.

Achats et Pro

Comment restaurer mes achats ?

Ouvrez les reglages de l'app, allez dans Achats integres, puis utilisez Restaurer les achats.

Qui gere le paiement ?

Les abonnements et l'achat a vie sont geres par Apple via l'App Store. Stockly Reserve ne recoit pas vos informations bancaires.

Comment resilier un abonnement ?

La resiliation se fait dans les reglages de votre compte Apple, section Abonnements.

Quelles conditions s'appliquent ?

Les conditions standard Apple s'appliquent aux achats integres : Apple Standard EULA.

Sauvegarde et changement d'iPhone

Sans foyer partage, utilisez l'export JSON avant de changer d'iPhone ou de supprimer l'app. Avec un foyer partage, synchronisez les modifications importantes avant de fermer l'app.

  • Export JSON : utile comme sauvegarde locale.
  • Import JSON : restaure les donnees contenues dans le fichier.
  • iCloud : synchronise les donnees d'un foyer partage entre membres acceptes.
